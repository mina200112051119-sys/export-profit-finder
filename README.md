# Export Profit Finder

輸出せどり支援ツールです。

## 現在の完成形

- 5カテゴリ対応：ポケモンカード／ポケモン関連サプライ用品／釣具／カメラ／レトロゲーム
- キーワード検索・写真から探す
- カテゴリ別ランキング・TOP10
- 利益、利益率、売れやすさ、相場安定性、在庫リスク、手数料などをまとめた100点評価
- 30・60・90日後の値下げシミュレーション
- 売れ残りリスクと損益分岐点の確認
- 商品詳細の開閉とモーダル内スクロール
- 仕入れ価格の根拠・仕入れ先候補の比較
- eBay現在出品データと為替の取得
- 日次スナップショット保存と手動更新
- 4人で独立して利用できる共有データ構成

## 現在のデータ上の注意

eBayの過去販売実績は Marketplace Insights API を利用する設計ですが、このAPIは現在「restricted」で、新規利用者には公開されていません。そのため、販売実績が取得できない場合に架空の販売実績を作らず、現在出品データを使った判定にフォールバックします。

## GitHub Pages

このリポジトリの `index.html` を GitHub Pages で公開すると、Webアプリとして開けます。

1. GitHubのリポジトリで **Settings** を開く
2. **Pages** を開く
3. Source を **GitHub Actions** にする
4. `pages.yml` の実行完了を確認する

公開URLは通常 `https://mina200112051119-sys.github.io/export-profit-finder/` です。

## Vercel側

`vercel.json` で `/api/daily-refresh` を毎日実行する設定です。日次更新には永続保存先の設定が必要です。

## 開発方針

実データとして取得できない数値はサンプル値と明示し、推定値を実績値として表示しない方針です。


## 完成形の判定基準（2026-09-21）

このツールは「商品を買うためのツール」ではなく、**輸出候補を比較して、リスクと利益の根拠を確認する分析ツール**とする。

### 1. 1商品で確認する情報
- eBay現在出品価格・送料・状態・商品ページ
- eBay過去販売実績（取得可能な場合のみ）
- 過去90日販売件数・販売価格中央値
- 現在の出品件数
- 国内仕入れ候補（メルカリ／スニダン／ヤフオク）は、価格・状態・送料を同条件で比較
- eBay手数料、海外手数料、為替換算手数料、送料、国内経費を差し引いた利益
- 現在価格、30日、60日、90日の価格下落を想定した利益
- データの信頼度と、信頼度を下げている理由

### 2. ランキング
カテゴリーごとに、以下を同時に比較する。
- 売れやすさの根拠
- リスク調整後利益
- 現在利益
- 相場安定性
- 90日後の下振れリスク
- データ信頼度
- 手数料負担

ランキングは「実データが多い商品」と「推定しかできない商品」を同じ確度として扱わない。

### 3. 「売れ残り」を隠さない
販売実績が取得できない場合、販売件数を推定値として実績のように表示しない。
また、30/60/90日シナリオは将来価格の保証ではなく、下落時の損失幅を確認するための試算として表示する。

### 4. 4人で安全に利用する
- eBay APIキーなどの秘密情報はブラウザに置かない
- Vercel側でAPIを実行する
- 日次データは共有ストレージに保存する
- 手動更新は共有元データを破壊せず、その時点の取得結果として扱う
- 端末ごとのlocalStorageには個人の表示・経費設定だけを保存する
- 自動更新は1日1回
- 取得失敗時は架空データに切り替えない

### 5. 外部サイトの扱い
メルカリは自動取得やスクレイピングを禁止する規定があり、SNKRDUNKもクローリング・スクレイピング等を禁止しているため、規約に反する自動取得は実装しない。メルカリ・SNKRDUNK・ヤフオクについては、公式に許可されたAPI等が確認できた範囲だけ自動取得対象とする。現時点では国内3サイトを「自動取得できた」と偽装せず、商品検索リンクとユーザー確認を残す。 citeturn0search1turn0search3

### 6. eBayの制約
eBay Browse APIでは現在の出品検索・画像検索が可能。一方、Marketplace Insights APIは現在restrictedで新規利用者には公開されていないため、過去販売実績はアクセス権がある場合だけ実データとして使用する。取得できない場合は「販売実績データなし」と明示する。 citeturn1search0turn1search4
