# Export Profit Finder

輸出せどり支援ツールです。

## 現在の完成形

- 5カテゴリ対応：ポケモンカード／ポケモン関連サプライ用品／釣具／カメラ／レトロゲーム
- キーワード検索・写真から探す
- カテゴリ別ランキング・TOP10
- 利益、利益率、売れやすさ、相場安定性、在庫リスク、手数料などをまとめた100点評価
- 30・60・90日後の値下げシミュレーション
- 売れ残りリスクと損益分岐点の確認
- 商品詳細の開閉とモーダル内スクロール
- 仕入れ価格の根拠・仕入れ先候補の比較
- eBay現在出品データと為替の取得
- 日次スナップショット保存と手動更新
- 4人で独立して利用できる共有データ構成

## 現在のデータ上の注意

eBayの過去販売実績は Marketplace Insights API を利用する設計ですが、このAPIは現在「restricted」で、新規利用者には公開されていません。そのため、販売実績が取得できない場合に架空の販売実績を作らず、現在出品データを使った判定にフォールバックします。

## GitHub Pages

このリポジトリの `index.html` を GitHub Pages で公開すると、Webアプリとして開けます。

### 公開設定

1. GitHubのリポジトリで **Settings** を開く
2. **Pages** を開く
3. Source を **GitHub Actions** にする
4. `pages.yml` の実行完了を確認する

公開URLは通常 `https://mina200112051119-sys.github.io/export-profit-finder/` です。

## Vercel側

`vercel.json` で `/api/daily-refresh` を毎日実行する設定です。日次更新には永続保存先の設定が必要です。

## 開発方針

実データとして取得できない数値はサンプル値と明示し、推定値を実績値として表示しない方針です。
