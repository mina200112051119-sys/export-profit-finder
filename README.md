# Export Profit Finder

輸出せどり支援ツールの試作版です。

## GitHub Pages

このリポジトリの `index.html` を GitHub Pages で公開すると、SafariからWebアプリとして開けます。

### 公開設定

1. GitHubのリポジトリで **Settings** を開く
2. **Pages** を開く
3. Source を **Deploy from a branch** にする
4. Branch を **main**、フォルダを **/(root)** にする
5. Save

公開URLは通常 `https://mina200112051119-sys.github.io/export-profit-finder/` です。

※現在は試作版のため、為替・eBay相場・仕入れ先データなどはサンプルです。
